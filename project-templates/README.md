# Project Templates

`PastureStack Native` is the reviewed default project template. It composes
the enabled network, encrypted overlay, scheduling, and health infrastructure
templates without requiring a separate catalog host or private image registry.

Historical project templates remain in the preserved upstream Git history but
are not exposed by the current tree because their dependencies have not passed
the PastureStack image, licensing, and runtime gates.
