# Layer 2 Flat Network

The image uses the official Ubuntu 26.04 Brotli package from [USN-8956-1](https://ubuntu.com/security/notices/USN-8956-1).

This driver connects managed workloads to a shared Layer 2 subnet through a host bridge. It does not provide encryption.

Numeric revision 11 (display version `v0.3.9`) uses the published image `ghcr.io/pasturestack/ipsec-vxlan-overlay-network:v0.14.44`.
Previous revision 10 and `ghcr.io/pasturestack/ipsec-vxlan-overlay-network:v0.14.43` remain available.
Questions, environment, resource parameters, volumes, permissions and plugin ownership are unchanged.
Exact publication records are in `catalog-images.json`; environment acceptance remains separate.
