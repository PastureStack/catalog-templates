# Layer 2 Flat Network

This driver connects managed workloads to a shared Layer 2 subnet through a host bridge. It does not provide encryption.

Numeric revision 9 (display version `v0.3.7`) uses the published image `ghcr.io/pasturestack/ipsec-vxlan-overlay-network:v0.14.42`.
Previous revision 8 and `ghcr.io/pasturestack/ipsec-vxlan-overlay-network:v0.14.41` remain available.
Questions, environment, resource parameters, volumes, permissions and plugin ownership are unchanged.
Exact publication records are in `catalog-images.json`; environment acceptance remains separate.
