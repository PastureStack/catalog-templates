# PastureStack 網路診斷

此基礎架構範本會安裝一個需要驗證的彙整服務，並在每台符合條件的
受管主機上安裝一個非 root 蒐集器。蒐集器只會傳送有明確上限的彙整
計數與去識別化主機代碼，不會傳送介面名稱、IP 或 MAC 位址、路由、
DNS 解析設定、主機名稱、容器或處理程序名稱、命令、環境變數、工作
負載內容、檔案、登入資訊或日誌。

## 安裝

請提供 32 到 256 個字元的隨機權杖。相同權杖用於授權蒐集器上傳及
管理者 API 請求。商店表單會遮蔽此值；它只會透過容器環境變數提供，
不接受命令列參數，也不會寫入應用程式日誌。

服務預設公開 `8091` 連接埠，以免與使用 `8080` 的控制平面衝突。
安裝後可開啟 `http://受管主機:8091/` 使用英文管理頁面，或送出
`Accept-Language: zh-TW` 取得繁體中文。健康狀態端點可公開存取；
摘要與診斷封存端點則需提供
`Authorization: Bearer <collection-token>`。

快照會保留在堆疊專用的 `network-diagnostics-data` 本機磁碟區。
將服務移到其他主機前，請先備份或移轉該磁碟區。移除堆疊時是否刪除
磁碟區，取決於管理者選擇的控制平面清理選項。

## 執行界線

代理程式採全域排程，只會透過唯讀掛載讀取 `/proc`、
`/etc/resolv.conf` 與 `/etc/machine-id`。機器識別碼只作為本機
HMAC-SHA-256 去識別化輸入，不會傳送出去。兩個容器均不要求特權
模式、主機網路、主機 PID、Linux Capability、容器引擎 Socket 或
可寫入的主機儲存空間。服務以數字使用者 `65532` 執行，映像不含
Shell。
