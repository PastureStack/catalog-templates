# 每主機子網路

此 driver 路由受管主機子網路，不提供加密；主機 NAT 與主機連接埠仍由網路外掛管理器維護。

數字修訂 7（顯示版本 `v0.3.5`）使用已發布的 `ghcr.io/pasturestack/ipsec-vxlan-overlay-network:v0.14.42`。
舊修訂 6 及 `ghcr.io/pasturestack/ipsec-vxlan-overlay-network:v0.14.41` 保留可用。
問題、環境、資源參數、磁碟區、權限與 plugin 職責不變。
精準發布記錄見 `catalog-images.json`，環境驗收仍須分開確認。
