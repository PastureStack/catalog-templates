# 資源排程器 v0.8.16

此範本會把可正常運作的 PastureStack 資源排程器部署成控制平面的
排程代理程式。排程器使用既有的控制平面事件及中繼資料契約，同時採用
原生 PastureStack 執行檔、除錯選項、公開映像與語意化版本標籤。

執行環境使用 UID/GID `10001:10001`。只有排程器執行檔具備綁定
相容健康檢查連接埠的權限。

此版本會在控制平面事件訂閱正常中斷或發生錯誤後重新連線，並在中繼
資料監看發生錯誤或已攔截的異常後重新啟動監看程序。

`/healthcheck` 只回報處理程序是否存活；`/readiness` 則回報控制平面與
中繼資料相依服務目前是否可用。因此，控制平面進行計畫性重新啟動時，
排程器可以暫時呈現尚未就緒，而不會因此被替換容器。
