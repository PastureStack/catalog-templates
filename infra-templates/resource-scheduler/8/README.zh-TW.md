# 資源排程器

此基礎架構代理程式依控制平面事件與目前中繼資料狀態排程原生工作負載。

數字修訂 8（顯示版本 `v0.8.22`）使用已發布的 `ghcr.io/pasturestack/resource-scheduler:v0.8.22`。
舊修訂 7 及 `ghcr.io/pasturestack/resource-scheduler:v0.8.21` 保留可用。
問題、環境、資源參數、磁碟區、權限與 plugin 職責不變。
精準發布記錄見 `catalog-images.json`，環境驗收仍須分開確認。
