# Resource Scheduler

The image uses the official Ubuntu 26.04 Brotli package from [USN-8956-1](https://ubuntu.com/security/notices/USN-8956-1).

This infrastructure agent schedules native workloads from control-plane events and current Metadata state.

Numeric revision 10 (display version `v0.8.24`) uses the published image `ghcr.io/pasturestack/resource-scheduler:v0.8.24`.
Previous revision 9 and `ghcr.io/pasturestack/resource-scheduler:v0.8.23` remain available.
Questions, environment, resource parameters, volumes, permissions and plugin ownership are unchanged.
Exact publication records are in `catalog-images.json`; environment acceptance remains separate.
