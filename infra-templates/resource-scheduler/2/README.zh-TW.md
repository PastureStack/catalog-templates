# 資源排程器 v0.8.15

此範本會把可正常運作的 PastureStack 資源排程器部署成控制平面的
排程代理程式。排程器使用既有的控制平面事件及中繼資料契約，同時採用
原生 PastureStack 執行檔、除錯選項、公開映像與語意化版本標籤。

執行環境使用 UID/GID `10001:10001`。只有排程器執行檔具備綁定
相容健康檢查連接埠的權限。

此版本會把相同工作負載重試同一項主機連接埠保留視為冪等操作，但仍會
拒絕由其他工作負載擁有的衝突保留。

排程器也會在中繼資料長輪詢暫時逾時後繼續重試，而不會終止處理程序。
正式環境升級後已連續健康執行超過四分鐘，容器只啟動一次；被替換的
舊版在相同中繼資料工作負載下曾重複重新啟動。
